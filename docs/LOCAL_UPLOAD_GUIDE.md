# تکمیل انتقال بسته کامل به GitHub

در محیط اجرای فعلی، اتصال GitHub امکان ایجاد فایل متنی و Git blob از محتوای ارسالی را دارد، اما مسیر مستقیم انتقال فایل‌های باینری محلی (CSV/ZIP/XLSX/PDF/PNG) به GitHub را در اختیار نمی‌گذارد. برای جلوگیری از ادعای نادرست، فایل‌های باینری در manifest با وضعیت «در انتظار انتقال» باقی مانده‌اند.

## بسته یکپارچه
فایل `REPOSITORY_UPLOAD_BUNDLE.zip` شامل snapshot فایل‌های موجود در محیط تحلیل است؛ شامل داده‌های خام هشت صندوق، MarketWatch، اسناد PDF/Markdown، کدها، گزارش‌ها، خروجی‌های CSV/Excel/PNG، بسته ۶۰ Skill و ZIPهای بک‌تست.

پس از دریافت ZIP و استخراج آن، ساختار آن را در ریشه یک clone از این مخزن کپی کنید. سپس:

```bash
git clone https://github.com/mtaghipourpars-dotcom/-tsetmc_05.git
cd -tsetmc_05
# محتویات استخراج‌شده بسته را در این پوشه کپی کنید.
git add .
git status
git commit -m "Upload complete research data and backtest artifacts"
git push origin main
```

## توصیه‌های انتشار
- قبل از push، `git status` را بررسی کنید تا فایل‌های موقت یا اطلاعات محرمانه وارد نشوند.
- فایل‌های CSV حجیم و خروجی‌های ZIP را در صورت عبور از محدودیت GitHub با Git LFS نگهداری کنید.
- برای هر فایل خام، SHA-256 را پیش و پس از انتقال مقایسه کنید.
- هیچ فایل خامی را با نسخه پردازش‌شده یا داده تخمینی جایگزین نکنید.

## وضعیت
این راهنما به معنی انجام push فایل‌های باینری نیست. پس از اجرای دستورات بالا و مشاهده commit در GitHub، می‌توان انتقال را کامل‌شده اعلام کرد.
