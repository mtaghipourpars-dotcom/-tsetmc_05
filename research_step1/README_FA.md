# گام اول اصلاح سامانه نوسان‌گیری

این بسته، ممیزی داده و یک پژوهش اکتشافی روزانه قابل بازتولید است؛ سامانه نهایی و بازسازی موتور قبلی نیست. خروجی‌ها با داده واقعی مخزن ساخته شده‌اند. تصمیم ارسال سفارش یا ادعای سودآوری قابل اجرا تولید نمی‌شود.

## شروع در ویندوز یا لینوکس

از داخل پوشه این فایل:

```bash
python -m pip install -r requirements.txt
python src/run.py --data Data
python -m unittest discover -s tests -v
python -m http.server 8000
```

سپس `http://localhost:8000/results/dashboard.html` را باز کنید. صفحه ایستا، تاریخی و فاقد اتصال کارگزاری است. اگر این پوشه داخل مخزن GitHub است، مسیر داده در دستور اجرا `../Data` است. در بسته ZIP، پوشه Data همراه قرار دارد. استفاده مجدد از داده تابع حقوق منبع اصلی است؛ مجوز بازتوزیع عمومی مستقلی احراز نشده است.

## اقلام

- `PREREGISTRATION_FA.md`: فرضیه و قواعد ثبت‌شده پیش از اولین اجرای عددی این نسخه.
- `REPORT_FA.md`: یافته‌ها، محدودیت‌ها و نتیجه تصمیم.
- `config.json`: ثبت پیکربندی اصلی؛ برای جلوگیری از ابهام، ثابت‌های سناریو و قواعد دقیق در `src/run.py` تعریف شده‌اند. این فایل رابط تنظیم پویا همه پارامترها نیست.
- `src/run.py`: ممیزی، سیگنال، شبیه‌سازی، معیارها و داشبورد.
- `src/audit_snapshots.py`: تطبیق قیمت و حجم صندوق‌ها با ده دیده‌بان.
- `tests/`: داده مصنوعی فقط برای آزمون موتور؛ هیچ عملکرد اقتصادی از آن استخراج نشده است.
- `results/`: معاملات، سفارش‌ها، منحنی سرمایه، شاخص‌ها، همبستگی، کیفیت و fingerprint ورودی.

بازده و افت در CSV به صورت اعشاری ثبت شده‌اند. همه مبالغ خام مشروط به فرض ریال هستند. ۱۰ ریال معادل یک تومان است. کد با Python 3 و نسخه‌های ثبت‌شده numpy/pandas اجرا شد. seed بازنمونه‌گیری بلوکی ۱۷۳ است.

هر بار اجرا خروجی‌های همین پوشه را بازنویسی می‌کند. فایل‌های Data تغییر نمی‌کنند. ۱۵۹ ردیف ارزیابی شامل ۱۰۸ شبیه‌سازی راهبرد، ۲۴ معیار هم‌افق، ۲۴ معیار قیمت منفعل و ۳ معیار نقد است؛ این‌ها ۱۵۹ راهبرد مستقل نیستند. تعداد زیاد آزمون‌ها و کوچک بودن نمونه، مانع ادعای کشف مزیت است.
