# سامانه پژوهش نوسان‌گیری ایران

هدف فاز اول: فرصت‌های کوتاه‌مدت ۱ تا ۱۰ جلسه در دارایی‌های منتخب، با یک موقعیت به اندازه کل سرمایه پس از هزینه، یا نقد. ورود ترجیحی در جذب صف فروش و خروج در تقاضای صف خرید، بدون ادعای اثبات آن با داده روزانه.

## وضعیت فعلی — ۱۲ نوامبر ۲۰۲۶

داده‌های واقعی در `Data/` هستند (حرف D بزرگ): ۸ سابقه روزانه صندوق‌ها و ۱۰ دیده‌بان بازار. کد موتورهای قدیمی که در گزارش‌های ۶ نوامبر نام برده شده‌اند در snapshot مبنای این اصلاح حاضر نبود؛ نتیجه‌های قدیمی از آن snapshot قابل بازتولید نبودند.

نسخه تازه `research_step1/` شامل کد و گزارش قابل بازتولید، ممیزی داده، معاملات، سفارش‌ها، منحنی سرمایه و داشبورد تاریخی است. این نسخه بازسازی موتور قدیمی نیست. پنج آزمون موتور پاس شده است.

آزمون نمونه، پایداری لازم نداشت: برای سرمایه فرضی ۱۰۰ میلیون تومان، بازده نسخه ساده در اعتبارسنجی ۲۰۲۵ حدود ۴۷٪ منفی و در آزمون زمانی ۲۰۲۶ حدود ۴۶٪ مثبت بود. شرط همبستگی منفی طلا/سهام نتیجه ۲۰۲۶ را بهتر نکرد. ارقام به فرض‌های اجرای روزانه و هزینه وابسته‌اند؛ راهبرد برای استفاده عملیاتی رد شده است.

اعتبار صف، تعدیل و تعرفه تاریخی هنوز تأیید نشده؛ داده روزانه جای دفتر سفارش را نمی‌گیرد. سود پیش‌بینی‌شده یا موقعیت واقعی در داشبورد ساخته نشده است.

## اجرا

از ریشه مخزن:

```bash
python -m pip install -r research_step1/requirements.txt
python research_step1/src/run.py --data Data
python -m unittest discover -s research_step1/tests -v
python -m http.server 8000
```

داشبورد: `http://localhost:8000/research_step1/results/dashboard.html`
