# Iran TSE/IFB Trading Research System

مخزن مرکزی مستندات، داده‌های پژوهشی و کدهای سامانه معاملاتی بازار سرمایه ایران.

## هدف
تمرکز سامانه بر انتخاب دارایی‌های قابل معامله در بورس تهران و فرابورس با افق کوتاه‌مدت است. افق انتخاب سهام در موتور B برابر ۱ تا ۵ جلسه معاملاتی است. نقدشوندگی و امکان خروج، کیفیت صف، جریان حقیقی/حقوقی، رژیم بازار و ریسک اجرا بر هر امتیاز بازدهی مقدم‌اند.

## وضعیت فعلی
- Engine A: بازپخش روزانه چرخش هشت صندوق و نسخه Risk-Limited در محیط تحلیل اجرا شده است.
- Engine B: مشخصات طراحی و الزامات غربالگری وجود دارد؛ بک‌تست جامع سهام ۱ تا ۵ روزه هنوز تکمیل نشده است.
- Queue validation: انجام نشده؛ فایل MarketWatch موجود فقط یک snapshot است، نه تاریخچه دفتر سفارش.
- همه نتایج تاریخی و تخمینی‌اند؛ هیچ تضمین بازدهی یا قابلیت اجرای سفارش واقعی ارائه نمی‌کنند.

## ساختار مخزن
- `docs/`: معماری، روش‌شناسی، وضعیت اعتبارسنجی و محدودیت‌ها.
- `skills/`: کاتالوگ و مشخصات ۶۰ مهارت سیستم.
- `src/`: کدهای بازپخش و ابزارهای تحلیل.
- `data/raw/`: داده‌های خام تاریخی و snapshot بازار (در بسته داده جداگانه).
- `data/processed/`: خروجی‌های پردازش‌شده و نتایج بک‌تست.
- `reports/`: گزارش‌های ممیزی و نتایج.
- `artifacts/`: بسته‌های ZIP، Excel و نمودارها.

## نکته مهم درباره داده‌ها
فایل‌های داده خام و باینری باید با نسخه اصلی و hash کنترل شوند. تا زمانی که فایل‌های خام و خروجی‌های پیوست‌شده در این مخزن قابل مشاهده نباشند، README به‌تنهایی به معنی انتقال داده‌ها نیست. وضعیت هر فایل در `docs/UPLOAD_MANIFEST.md` ثبت می‌شود.

## اصول غیرقابل‌مذاکره
1. Liquidity First؛ امکان خروج باید پیش از ورود سنجیده شود.
2. تمام داده‌ها با برچسب LIVE / HISTORICAL / SIMULATED / DEMO / ASSUMPTION تفکیک شوند.
3. هیچ ادعای Queue-Validated بدون داده تاریخی سفارش و معاملات واقعی مجاز نیست.
4. بازده، CAGR، Sharpe و Drawdown باید از یک دفتر کل واحد Equity محاسبه شوند.
5. هزینه کارمزد، لغزش، اجرای ناقص و محدودیت دامنه نوسان باید شفاف باشد.
6. معامله واقعی و ارسال سفارش نیازمند تأیید صریح انسانی است.

## آخرین محدوده داده تاریخی بررسی‌شده
هشت صندوق: موج، شتاب، اهرم کاریزما، توان، عیار، کهربا، آلتون و اعتماد پارسیان. دوره گزارش‌شده در تحلیل‌های ۶ نوامبر ۲۰۲۶، تا ۴ نوامبر ۲۰۲۶ است. فایل MarketWatch در این مجموعه یک snapshot HTML با پسوند XLS بوده است.
