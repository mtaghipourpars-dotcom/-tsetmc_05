نصب دیدبان بدون Docker — نسخه ۳٫۱

این نسخه با Python و SQLite اجرا می‌شود. نصب Docker، PostgreSQL، Node.js یا دسترسی Administrator لازم نیست. رابط وب، ذخیره‌سازی، جمع‌آوری پس‌زمینه و زمان‌بندی در یک فرایند اجرا می‌شوند. نشانی وب فقط روی کامپیوتر خودتان در دسترس است.

۱. نصب Python

اگر Python 3.12 یا جدیدتر دارید، به مرحله بعد بروید. نسخه پیشنهادی و آزموده‌شده Python 3.12 است.

از https://www.python.org/downloads/windows/ نصب‌کننده ۶۴ بیتی Python 3.12 را بگیرید. گزینه **Add python.exe to PATH** را فعال و نصب برای حساب کاربری خودتان را انتخاب کنید؛ نیازی به Install for all users نیست.

در Command Prompt با `py -3 --version` یا `python --version` نسخه را بررسی کنید.

۲. استخراج ZIP

روی ZIP راست‌کلیک و **Extract All** را انتخاب کنید. پوشه را در مسیری قابل نوشتن مانند `C:\Users\YourName\Documents\Didban` قرار دهید. برنامه را داخل ZIP یا Program Files اجرا نکنید. پوشه Data باید کنار market_data_service باقی بماند.

۳. اجرای برنامه

روی **START_WINDOWS.bat** دوبار کلیک کنید. بار اول محیط مجزای Python ایجاد و کتابخانه‌ها از اینترنت دریافت می‌شوند؛ چند دقیقه صبر کنید. اگر دریافت کتابخانه خطا داد، اتصال اینترنت را اصلاح و دوباره همان فایل را اجرا کنید. در اجراهای بعد نصب تکرار نمی‌شود مگر فهرست نیازمندی‌ها عوض شده باشد.

مرورگر به نشانی **http://127.0.0.1:8000** باز می‌شود. اگر خودکار باز نشد، نشانی را دستی وارد کنید. پنجره سیاه اجرای برنامه را باز نگه دارید.

روش دستی از ریشه پوشه پروژه در Command Prompt:

py -3 market_data_service\scripts\launch_local.py

اگر فرمان py ندارید، به جای آن python بنویسید. اگر پورت ۸۰۰۰ اشغال است:

START_WINDOWS.bat --port 8001

سپس http://127.0.0.1:8001 را باز کنید. برنامه فقط یک نسخه هم‌زمان روی یک پوشه داده اجرا می‌کند.

۴. داده و جمع‌آوری

در اولین اجرا، ۱۰٬۲۲۷ ردیف سوابق تاریخی موجود در پوشه Data برای هشت نماد وارد می‌شود. این داده‌ها تاریخی و از فایل‌های مخزن هستند؛ داده زنده محسوب نمی‌شوند. صف اولیه جمع‌آوری از TSETMC خودکار ساخته می‌شود و پردازشگر آن همراه برنامه فعال است. دریافت اطلاعات جدید به دسترسی شبکه شما به سرویس بستگی دارد. وضعیت درخواست‌ها، خطاها و پیشرفت را در صفحات منابع و جمع‌آوری ببینید. کار متوقف‌شده را بعد از رفع مشکل از رابط ادامه دهید. زمان‌بندی بر مبنای Asia/Tehran و فقط هنگام باز بودن برنامه فعال است؛ اجرای مجدد کارهای زمان‌بندی‌شده زمان خاموشی را بازپخش نمی‌کند.

برای فرمان‌های مدیریتی، فایل **market_data_service/.env.local** را با Notepad باز کنید. مقدار پس از `ADMIN_TOKEN=` را در بخش کلید مدیریت رابط وب وارد کنید. این کلید در همان نصب ساخته می‌شود و نباید منتشر شود. کلید BrsApi جداست؛ در صورت نیاز آن را در `BRS_API_KEY=` همین فایل وارد و برنامه را راه‌اندازی مجدد کنید. TSETMC منبع پیش‌فرض است و کلید BrsApi برای آن لازم نیست. فایل .env مربوط به مسیر Docker است و در این روش خوانده نمی‌شود. متغیرهای محیط سیستم طبق قواعد تنظیمات اولویت دارند؛ مسیر دیتابیس این اجرا همیشه SQLite محلی است.

۵. ذخیره، توقف، پشتیبان

دیتابیس پایدار در **market_data_service/local_data/didban.db** قرار دارد؛ با بستن برنامه حذف نمی‌شود. گزارش‌ها در همین پوشه‌اند. SQLite برای اجرای شخصی محلی مناسب است؛ جمع‌آوری طولانی‌مدت داده پرتعداد به فضای دیسک کافی نیاز دارد.

برای توقف در پنجره اجرا **Ctrl+C** بزنید و تا پایان توقف صبر کنید. بستن مرورگر برنامه را متوقف نمی‌کند. برای اجرای مجدد همان START_WINDOWS.bat را باز کنید. وضعیت صف و داده‌های قبلی حفظ می‌شوند.

برای پشتیبان، ابتدا برنامه را متوقف کنید و سپس **تمام پوشه local_data** و فایل **.env.local** را در جای امن کپی کنید؛ فایل‌های جانبی SQLite نیز در صورت وجود باید همراه باشند. برای بازیابی، در حالت توقف همین فایل‌ها را در محل قبلی برگردانید. برای انتقال نسخه جدید، local_data و .env.local قبلی را حفظ کنید؛ مهاجرت ساختار دیتابیس هنگام شروع انجام می‌شود.

Linux/macOS

با Python 3.12 و قابلیت venv از ریشه پروژه اجرا کنید:

python3 market_data_service/scripts/launch_local.py

در این بسته، READMEها و فایل‌های Docker برای سازگاری با روش قبلی باقی مانده‌اند؛ راهنمای اجرای مستقیم همین فایل است.
