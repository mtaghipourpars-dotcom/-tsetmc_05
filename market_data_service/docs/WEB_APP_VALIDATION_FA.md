# اعتبارسنجی وب‌اپ دیدبان — نسخه ۳

تاریخ: ۱۲ نوامبر ۲۰۲۶. این گزارش مرجع نسخه وب‌اپ است؛ گزارش‌های قبلی برای تاریخچه حفظ شده‌اند.

| بررسی | نتیجه واقعی |
|---|---|
| آزمون نهایی | **۲۰۵ موفق**، شامل PostgreSQL؛ هیچ skip در اجرای نهایی |
| PostgreSQL | نسخه 16.2؛ اجرا و اتصال TCP واقعی |
| Migration | 0001، 0002 و 0003 اعمال شدند؛ alembic check بدون اختلاف |
| بانک | ۲۵ جدول؛ از جمله صف پایدار collection_jobs/collection_tasks |
| داده اولیه | ۱۰٬۲۲۷ رکورد تاریخی هشت صندوق؛ صفر رکورد ردشده |
| Uvicorn/FastAPI | اجرا و HTTP واقعی موفق |

| مرورگر | پنل RTL، جست‌وجوی عیار، نمودار، پروفایل نماد و کاوش رکوردها با داده واقعی مخزن بررسی شدند |

خروجی نهایی تست در test_output_webapp_postgresql.txt و شواهد HTTP/صف در webapp_runtime_verification.json موجود است. هشدار TestClient/HTTPX مربوط به deprecation کتابخانه محیط است و شکست آزمون نیست.

## آزمون‌های رفتاری جدید

- ساخت job با کنترل دسترسی، مکث و ادامه از API؛ رد بازه ناقص و انتخاب خالی.
- کشف نماد و تولید مراحل اطلاعات، تاریخچه، سهامداران و جزئیات تاریخ‌دار.
- ذخیره تاریخچه و پایان صف با منبع ساختگی صریح در آزمون، بدون HTTP بیرونی.
- مکث پس از قطعی سرویس و بازیابی صف از یک مدیر جدید با همان بانک.
- جلوگیری از تکرار aliasهای کاتالوگ و ارسال شناسه سهام به endpoint مخصوص شاخص.
- حفظ نتیجه موفق در برنامه‌ریزی تکراری task.
- خواندن قیمت و profile و CSV از رکورد ذخیره‌شده؛ نرمال‌سازی ی/ي در جست‌وجو.

## حدود راستی‌آزمایی

در محیط فعلی دریافت تازه TSETMC همچنان پاسخ داده معتبر نداد. وب‌اپ این وضعیت را با گزارش و job قابل ادامه ثبت می‌کند. اطلاعات تاریخی اولیه به عنوان داده زنده ارائه نشده است. ادعای تکمیل آرشیو کل بازار ایران مطرح نمی‌شود.

پوشش collector شامل سرویس‌های عمومی و سرویس‌هایی است که پارامتر نماد/تاریخ آن‌ها از اطلاعات واقعی قابل تعیین است. سرویس‌های وابسته به شماره اطلاعیه، شناسه حراج و سایر شناسه‌های ویژه در نتیجه برنامه‌ریزی deferred ثبت می‌شوند؛ در پنل از کاتالوگ با شناسه واقعی قابل فراخوانی‌اند. مقدار Top=1000 برای برخی سرویس‌ها در params مشخص است؛ سقف خود ارائه‌دهنده و داده غیرقابل‌دسترسی به‌عنوان اطلاعات دریافت‌شده محسوب نمی‌شوند.

کنترل شروع/مکث/ادامه با توکن مدیریت در آزمون API بررسی شده است؛ ورود credential واقعی در مرورگر آزمایش نشده و کلید خصوصی به پنل یا Git بازگردانده نشده است. پیش‌نمایش مرورگر از SQLite توسعه با همان داده واقعی استفاده کرد؛ آزمون backend و صف جداگانه روی PostgreSQL واقعی اجرا شد.

اجرای این محیط موقت است. برای استفاده ماندگار، start.bat یا Compose در سیستم کاربر اجرا شود. شواهد اتصال بیرونی و آزمون شبکه مستقل گیت‌هاب در گزارش نسخه ۲ و github_runner_tsetmc_probe.json باقی مانده‌اند.

آزمون خودکار مخزن برای نسخه وب‌اپ نیز موفق شد: [GitHub Actions](https://github.com/mtaghipourpars-dotcom/-tsetmc_05/actions/runs/43221433766). خواندن تنظیمات و فایل‌های فارسی صریحاً UTF-8 شده است تا راه‌اندازی Windows به encoding پیش‌فرض سیستم وابسته نباشد.
