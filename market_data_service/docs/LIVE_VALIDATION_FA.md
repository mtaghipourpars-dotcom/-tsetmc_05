## نتیجه اتصال بیرونی

| منبع | نتیجه واقعی |
|---|---|
| BrsApi با کلید مجازشده کاربر | HTTP 403؛ صفحه خود سرویس می‌گوید کلید به علت عبور از ظرفیت مجاز مسدود است |
| cdn.tsetmc.com | HTTP 503 / upstream connection timeout |
| cdn10.tsetmc.com | HTTP 503 |
| www و دامنه اصلی TSETMC | HTTP 503 |
| old، members و service TSETMC | خطای upstream/timeout |
| سرویس SOAP/WSDL قدیمی | پاسخ معتبر دریافت نشد |
| webgw.tse.ir | خطای upstream/timeout |
| صفحه عمومی brsapi.ir | HTTP 200؛ این نتیجه به معنی کارکرد endpoint دارای کلید نیست |

پس از دریافت متن مسدودی، فراخوانی دارای کلید بیشتری انجام نشد. هیچ کلید یا نشانه خصوصی در مخزن ثبت نشده است. دورزدن مسدودی حساب یا ادعای دریافت داده معتبر انجام نشده است.

چهار مسیر اصلی در API محلی فراخوانی شدند؛ درخواست market_watch به سرویس بیرونی رسید و 503 گرفت؛ درخواست‌های بعدی تحت circuit breaker یک‌دقیقه‌ای پاسخ خطا گرفتند. probes مستقیم قبلی client_all و indices هم خطای اتصال داشتند. جدول ۱۳۶ مسیر، inventory قابل فراخوانی است و به‌عنوان ۱۳۶ endpoint زنده تأییدشده ارائه نمی‌شود.

## کارکرد نسخه جدید

- TSETMC مسیر اصلی دریافت است. BrsApi حفظ شده و fallback پس از فعال‌شدن حساب، با BRS_FALLBACK_ENABLED قابل روشن‌شدن است.
- تمام مسیرهای کاتالوگ به صورت GET با میزبان رسمی، پارامترهای قابل تنظیم و خروجی JSON، متن یا باینری قابل فراخوانی‌اند. پارامتر URL/credential از کاربر API داخلی پذیرفته نمی‌شود.
- mirror رسمی و TSETMC_PROXY_URL برای پراکسی متعلق به خود کاربر پشتیبانی می‌شود؛ مسیر شبکه ایران در این محیط فراهم نشد و مقدار جعلی برای آن ثبت نشده است.
- هر دریافت آرشیو، وضعیت، hash، منبع و کیفیت مستقل دارد. داده خالی، خطا و timestamp مفقود با موفقیت داده معتبر اشتباه گرفته نمی‌شوند.
- ساختار اولیه BrsApi شامل ۱۶ دسته حفظ شده است. داده‌های مستقیم همه خانواده‌ها در آرشیو/observations ذخیره می‌شوند؛ نگاشت تخصصی تمام خانواده‌ها به جدول جدا تکمیل نشده است.
- GETها از بانک می‌خوانند. دریافت داده روی POST مدیریتی و worker انجام می‌شود؛ خواندن داشبورد سهمیه API را مصرف نمی‌کند.

## محدوده‌ای که هنوز تأیید نشده است

دریافت موفق زنده از TSETMC در این شبکه و دریافت موفق با کلید فعلی BrsApi تأیید نشده‌اند. حساب BrsApi باید طبق پیام خود ارائه‌دهنده فعال شود؛ برای TSETMC، اجرای همین collector روی مسیر شبکه دارای دسترسی لازم است. این بسته برای آن اجرا آماده است و اتصال مجاز خود کاربر را می‌پذیرد، اما چنین مسیری در این جلسه واقعاً تأمین نشد.

اجرای محلی این جلسه موقت است؛ آدرس localhost آن در مرورگر رایانه کاربر سرویس نمی‌دهد. برای استفاده ماندگار، سرویس با Docker روی رایانه یا سرور خود کاربر اجرا شود.

## آزمون مستقل runner گیت‌هاب

برای بررسی یک مسیر شبکه مستقل، چهار سرویس اصلی روی هر دو میزبان cdn و cdn10، جمعاً هشت درخواست عمومی از runner گیت‌هاب ارسال شد. هیچ کلید BrsApi در این آزمون استفاده یا به گیت‌هاب منتقل نشد. همه درخواست‌ها با ConnectTimeout/ConnectError پایان یافتند؛ any_data_received=false است.

سبز بودن job این diagnostic به معنی اجرای موفق اسکریپت و ذخیره گزارش است؛ به معنی دریافت موفق داده نیست. خروجی کامل در github_runner_tsetmc_probe.json ثبت شده است.
